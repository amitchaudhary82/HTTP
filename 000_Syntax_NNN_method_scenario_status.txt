NNN_method_scenario_status.http
Recommended naming rules
Use always: Syntax
NNN : 3 digits numbering
Method: lowercase method name (get, put, post)
underscore _
scenario: scenario name covering everything rest as free text
status: expected status like 200, 403, 500
.http : extension






tool + server suffix:
  _telnet_local     telnet to the local Python mini server  (folder 1_telnet)
  _telnet_internet  telnet to an internet server, port 80   (folder 1_telnet)
  _openssl          openssl to an HTTPS server, port 443     (folder 2_openssl)
Example: 001_get_root_200_telnet_local.http
